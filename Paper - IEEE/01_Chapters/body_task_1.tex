For the binary classification performance analysis, a feature selection algorithm is implemented to iteratively find the ideal subset of features for each PQD class. The feature dropping algorithm is a greedy algorithm that iteratively removes features from the feature set based on their impact on the classification performance. The algorithm starts with the full set of features and evaluates the performance of a classifier using cross-validation. It then identifies the feature whose removal results in the highest improvement in the F1 score. This feature is dropped, and the process is repeated with the remaining features until no further improvement in F1 score can be achieved. If the F1 score stays constant or decreases only marginally, features are also dropped to ensure The final set of selected features is determined by majority voting across different classifiers, ensuring that the most relevant features for each PQD class are retained.

The process is repeated for four different classification models: Logistic Regression, Decision Tree, linear SVM and rbf SVM. They are combined through bagging using majority voting to form a final feature selection result. The results of the majority voting feature selection for the Swell target label are summarized in \autoref{tab:majority_voting_summary}. The recommended features for each target label are presented in \autoref{tab:recommended_features}.
