\section{Feature Selection for Recognition of PQDs}
The eight features in~\autoref{tab:extracted_features} were extracted from the PQD signals using S-transform and statistical analysis. A machine learning model can use these features to classify the PQDs into their respective classes. However, not all features may be equally important for the classification of every PQD class. Thus, as a first step, feature selection is performed to identify the most relevant features for each PQD class. For this, first physical relationships between the features and the PQDs are analyzed. Then, a graphical and statistical analysis of the features is performed. Finally, the features are selected based on a binary classification performance analysis similar to boosting. The results of the feature selection are summarized in the end of this section.

Starting with the normal case, trivially, none of the features is expected to show a difference. For the other PQD classes, a reasoning is provided as follows:
\begin{itemize}
    \item \textbf{Sag:} The voltage is reduced temporarily, due to a fault in the power system. Thus, most predominently, the expected minimal voltage amplitude is lower (F4). Additionally, depending on the duration of the sag, the maximum voltage amplitude (F3) might also be lower and number of points near zero (F8) might thus be higher. The standart deviation of the voltage (F2) might also be higher, because of the different voltage levels.
    \item \textbf{Swell:} The voltage is increased, which is expected to increase the maximum voltage amplitude (F3) and potentially also the minimum voltage amplitude (F4). Again, as for the sag, the TmA standard deviation (F2) might also be higher.
    \item \textbf{Interruption:} The voltage is interrupted, which is expected to lead to a higher number of points near zero (F8), a higher standard deviation of the voltage (F2), and a lower minimum voltage amplitude (F4). 
    \item \textbf{Transient:} A transient is most importantly characterized by an increased high frequency (F7) and potentially also medium frequency content (F6). 
    \item \textbf{Harmonics:} Harmonics are expected to lead to an increased amplitude of the third harmonic (F1) and an increased higher frequency content (F6, F7).
    \item \textbf{Flicker:} A varying voltage amplitude, as in FLicker, does not have a distinct correlation with any of the features. However, it is expected to potentially lead to an increased standard deviation of the voltage amplitude (F2) and a change in the maximum, as well as the minimum voltage amplitudes (F3, F4).
    \item \textbf{Sag with harmonics:} Since this PQD is a combination of a sag and harmonics, the expected features can be derived from their individual effects. Thus, the features expected to show a difference to the normal case, consider the sag features (F4, F2 and potentially F3, F8), as well as the harmonics features (F1, F6, F7).
    \item \textbf{Swell with harmonics:} Similarly, the expected features for this PQD can be derived from combining the individual effects of swell (F3, F4 and potentially F2), as well as harmonics (F1, F6, F7).
\end{itemize}
For a machine learning classifier it is important which features carry the most information for each specific PQD class. To determine this, the physical considerations are a starting point, but a more detailed data analysis is required. Especially, it has to be noted, that although a deviation from the normal case for a feature is an indicator for an issue in the power system, it does not necessarily give any information about the specific type of PQD. A feature, that is expected to show a distinct difference for multiple PQD classes (e.g. F7), might not be as useful for the multi class classification, as a feature that is strongly correlated with only one PQD class (e.g. F8).

\subsection{Statistical Feature Analysis}
% Use Task 1-Paul: Feature scoring-> highlight the most important features for each PQD class from both anova f-score and mutual information score.
Following the qualitative analysis, in the form of physical considerations and graphical analysis, a quantitative analysis of the features using statistical measures was performed. For this, the F-Score and the Mutual Information (MI) between each feature and the PQD classes were calculated. The F-Score is a measure of the linear relationship between a feature and the PQD classes and is calculated as~\cite{fisher1925statistical_fscore}:
\begin{align}\label{eq:feature_F-score}
F &= \frac{\text{Between-Group Mean squared}}{\text{Within-Group Mean squared}}\\
&= \frac{\frac{1}{C - 1} \sum_{c=1}^{C} n_c (\bar{x}_c - \bar{x})^2}{\frac{1}{N - C} \sum_{c=1}^{C} \sum_{i=1}^{n_c} (x_{ic} - \bar{x}_c)^2}.
\end{align}
The MI measures in general the amount of information that a feature provides about the PQD classes and can thus capture also non-linear, more complex relationships~\cite{kraskov2004estimating_MIscore}. It is calculated as:
\begin{equation}\label{eq:feature_MI-score} % based on shannon entropy
I(X; Y) = \sum_{y \in Y} \sum_{x \in X} p(x, y) \log \left( \frac{p(x, y)}{p(x)p(y)} \right)
\end{equation}
These two statistical measures were used, because they provide different perspectives on the relationship between the features and the PQD classes and are easily implementable using the \texttt{sklearn.feature\_selection} library. The results of the F-Score and MI calculations are shown in \autoref{fig:feature_relevance_heatmaps}.

\subsection{Feature Elimination using binary classification performance}

Finally, the feature selection was performed from a machine learning perspective, by evaluating the classification performance of each feature for each PQD class.
For the binary classification performance analysis, a feature selection algorithm is implemented to iteratively find the ideal subset of features for each PQD class. The feature dropping algorithm is a greedy algorithm that iteratively removes features from the feature set based on their impact on the classification performance. The algorithm starts with the full set of features and evaluates the performance of a classifier using cross-validation. It then identifies the feature whose removal results in the highest improvement in the F1 score. This feature is dropped, and the process is repeated with the remaining features until no further improvement in F1 score can be achieved. If the F1 score stays constant or decreases only marginally, features are also dropped. This ensures that features are only selected if the contribute significantly. That way the resulting subset will have the best score with the least computational effort.

The feature dropping algorithm is a greedy algorithm that iteratively removes features from the feature set based on their impact on the classification performance. The algorithm starts with the full set of features and evaluates the performance of a classifier using cross-validation. It then identifies the feature whose removal results in the highest improvement in the F1 score. This feature is dropped, and the process is repeated with the remaining features until no further improvement in F1 score can be achieved. If the F1 score stays constant or decreases only marginally, features are also dropped. This ensures that features are only selected if they contribute significantly. That way the resulting subset will have the best score with the least computational effort. 

To determine a final set of selected features for each PQD class, which is robust across different classifiers, the feature dropping algorithm is applied to four different classification models: Logistic Regression, Decision Tree, linear SVM and rbf SVM. The inclusion of non-linear models in this feature selection algorithm is important, as not all features correlate linearly with the PQD classes, as shown by the comparison of the F-scores and the MI in the previous section. The importance of these features would be missed, if only linear models were used. The selected features from each classifier are then combined through bagging using majority voting. This means that a feature is retained in the final set if it is selected by the majority of classifiers (i.e. selected by at least 2 out of the 4 classifiers). As an example, the results of the majority voting feature selection for the swell class are given in \autoref{tab:majority_voting_summary}. The recommended features for each class are summarized in \autoref{tab:recommended_features}.

Apart from a few exceptions, the recommended features for each PQD class are in line with the physical considerations,as well as the graphical and statistical analysis. Deceisive features, such as F1, that contain a lot of information about the PQD classes (e.g., see~\autoref{fig:feature_relevance_heatmaps}), can be found in all but one of the recommended feature sets. It can also be observed, that the different PQD classes have a different number of recommended features. This is due to the fact, that some PQD classes have a more distinct relationship with a specific feature, such as the interruption PQD class with F8. On the other hand, some PQD classes, such as the Flicker, require a combination of multiple features, as well as a non-linear model to achieve a good classification performance.
The selection can be verified by visualizing the selected features for each PQD class. Examplary,~\autoref{fig:swell_features} shows the distribution of the selected features for the Swell PQD class. It can be seen observed that F1 and F3 are sufficient to distinguish the Swell PQD class from all other PQD classes, which explains the high performance of the classifiers using only these two features.

\subsection{Feature Selection Conclusion}
% Combine the results of the previous sections. Elobarate that different features are important for different PQD classes and similar trends are visible throughout all Analysis methods. BUT, explain also, that different classification models may have different feature importances, as linear models rely on linear feature relationships, while non-linear models can capture more complex relationships etc. 

The ideal subset of features will always depend on the application since different types of classifiers may archieve optimal performance with different feature sets (e.g., linear vs. non-linear models). For the goal of finding one general feature set for every PQD class, the results of all analysis methods were compared with each other. Since the feature elimination using binary classification performance is the most structured and generalized approach, used for the feature selection, its resulting feature sets (see Table~\ref{tab:recommended_features}) can be interpreted as the final recommendation for the feature selection. These sets are in strong agreement with the other anlysis and provide good classification performance with compareatively low computational effort.
