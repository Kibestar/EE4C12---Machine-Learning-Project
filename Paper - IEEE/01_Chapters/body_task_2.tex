\section{Multiclass Classification of PQDs}
% Explain this: Three model types are trained and evaluated for the multiclass classification of PQDs. For the training all features were used, as there is no unique subset from task 1 that is optimal for all PQD classes. Stratified 5-fold cross-validation is used to evaluate each model type and optimize the hyperparameters. 
For the multiclass classification of PQDs, three different model types are trained, optimized and evaluated: Decision Trees (DT), Random Forests (RF) and Multi-Layer Perceptrons (MLP). Although, the feature selection process showed that binary classification of each PQD is possible with a subset of the available eight features, the union of all these subsets still includes F1 to F8. This is because, every feature was identified to be important for at least one PQD class. Therefore, for the multiclass classification, all features are used.

To evaluate each model type and optimize the hyperparameters, stratified 5-fold cross-validation is used. As scoring metric for each models hyperparameter optimization, the precision score for the Normal class, averaged from the different validation folds is used. Additionally, hyperparameter sets, that result in a too low average f1-macro score ($<0.9$) for any other PQD class are filtered out. This to ensure that the missclassifictation PQDs as Normal is minimized, as an undetected disturbance in the system can have critical consequences in a real-world power system. The average f1-macro score is used to ensure that the model performs well across all PQD classes. The implementation is done through a custom scorer which evaluates the precision score for the Normal class in each multiclass classification.

All models initially use a random search approach for hyperparameter tuning. Reason for this is that the non-linear models DT, RF and MLP have a large number of hyperparameters that can be tuned. Therefore, it is not feasible to perform a grid search over a large parameter space using the available computational resources. Instead, a random search approach is used, where a predefined number of random combinations of hyperparameters is evaluated. If the random search yields results which suggest the redundancy of certain hyperparameters, a grid search can be performed on the most promising hyperparameter combinations to further optimize the model. 

The best model of each model type is then evaluated on the holdout test set. Finally, a bagged model is created using the best hyperparameter sets for the three model types and combining their predictions using majority voting. This bagged model is then also evaluated on the holdout test set.

\subsection{Decision Tree Classifier}

Decision Trees are a non-linear model type that can be used for multiclass classification tasks. They work by recursively partitioning the feature space into smaller regions based on the values of the input features. Each internal node of the tree represents a decision based on a feature, and each final leaf node represents a class label. The decision tree is trained on the dataset using stratified 5-fold cross-validation to find the best hyperparameters. The hyperparameters that are tuned include the maximum depth of the tree (max\_depth), the minimum number of samples required to split an internal node (min\_samples\_split), the minimum number of samples required to be at a leaf node (min\_samples\_leaf), and the criterion used to decide on the optimal stump to be added to the node (criterion). The results of the hyperparameter tuning are shown in \autoref{tab:dt_evaluation_results}. The best combination of hyperparameters is highlighted in the table. This combination was chosen since it achieved the highest normal precision score.

\subsection{Random Forest Classifier}
% USE Task 2-Paul: Random Forest (RF) notebook -> Currently only the hyperparameter tuning is done, but the notebook can be extended to include the evaluation of the best model on the test set.
Random Forests are an ensemble learning method that combines multiple decision trees to improve the overall performance and robustness against overfitting of the model. Each decision tree is trained on a random subset of the training data and features, which helps to reduce overfitting and increase generalization. The final prediction is made by aggregating the predictions of all individual trees, through majority voting. Random Forests are particularly effective for multiclass classification tasks, as they can handle complex decision boundaries and interactions between features, while avoiding overfitting~\cite{ML_Refined_book}. In this work, a Random Forest classifier is trained on the dataset using stratified 5-fold cross-validation to find the best hyperparameters. The hyperparameters that are tuned include the number of trees in the forest (n\_estimators), the maximum depth of each tree (max\_depth), the minimum number of samples required to split an internal node (min\_samples\_split), the minimum number of samples required to be at a leaf node (min\_samples\_leaf), and the criterion used to decide on the optimal stump to be added to the node (criterion). The results of the hyperparameter tuning are shown in \autoref{tab:rf_evaluation_results}. The best combination of hyperparameters is again highlighted in the table. This combination was chosen since it achieved the highest normal precision score.

\subsection{Multilayer Perceptron}
% USE Task 2-Vossi: MLP notebook -> This already includes extensive hyperparameter tuning and a first version of the evaluation of the best model on the test set. The notebook can be extended, so that its evaluation is more comparable to the other two model types.

Multilayer Perceptrons (MLPs) are a class of feedforward artificial neural networks that consist of multiple layers of nodes, or neurons, which are interconnected in a directed graph. Each neuron in an MLP applies an activation function to a weighted sum of its inputs, allowing the network to learn complex, non-linear relationships between input features and output classes. To use an MLP for multiclass classification of PQDs, the model has to be trained on the dataset. As described before, this is done using stratified 5-fold cross-validation to find the best hyperparameters. MLPs come with a large number of hyperparameters that can be tuned. The most important ones are the number of hidden layers, the number of neurons in each hidden layer. In addition to that, we can also tune the activation function, the solver, the learning rate, and the regularization parameter. As explained before, random search is used to find the best combination of hyperparameters which is then used to train the final model, which is evaluated on the test set. The results of the hyperparameter tuning are shown in \autoref{tab:mlp_evaluation}. Since there where no obvious patterns visible, it was decided to not further tune the hyperparameters with grid search. The best combination of hyperparameters is highlighted in the table. This combination was chosen since it achieved the second highest normal precision score while having a macro f1-score that is significantly higher than the best normal precision score.

\subsection{Combined (Bagged) Model}
The final results of the three model types are compared in \autoref{tab:task2_final_validation}. The results show overall a very good performance in terms of the macro f1-score. The best model is the Random Forest model, which achieved a macro f1-score of 0.9822. In terms of the normal precision score, they all perform well but not good enough to be used in a real-world application. Here, the best model is again the Random Forest model, which achieved a normal precision score of 0.9281. To achieve a better performance, a bagged model is created from the best models of the three model types using soft voting which combines the probabilities of the individual models. The bagged model is then evaluated on the test set and the results are compared to the individual models.
